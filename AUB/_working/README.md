# Working files — not part of any handover

Nothing in this folder goes to AUB. It is design exploration and internal
notes kept because they explain decisions that are otherwise invisible.

- `mockups/` — layout options built to choose between before committing to one.
  `faculty-mockup.html` is the three full-bio layouts; AUB chose Option A.
  `header-mockup.html` and `hero-mockup.html` are the header and hero studies
  against the Executive MBA reference.
- `references/` — screenshots of other AUB sites used as design references.
- `PORTING-BRIEF-online-education.md` — the instructions used to carry a round
  of changes from one programme build to the other.

The rule this folder exists to protect: **a programme folder should contain
only what AUB receives.** Zip it, send it, and nothing is missing or surplus.
